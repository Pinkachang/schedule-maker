# TPBL 賽程排程工具

TPBL（台灣職業籃球大聯盟）2026-27 賽季的**客隊指派與賽程視覺化**單頁工具。

主場骨架（哪一隊哪天在自己主場打）由另一位同事掌握，本工具負責在既有的主場時段上**指派客隊**、即時檢查衝突、統計公平性與對戰分布，並匯出球團可直接使用的 Excel。

整個工具是**單一 `index.html` 檔**，無後端、無建置流程，丟上 GitHub Pages 即可運作。

> 想改程式碼、或要接手維護，請看 **`交接文件.md`**。本文只講「這是什麼、怎麼用」。

---

## 功能總覽

| 分頁 | 用途 |
|------|------|
| **排程** | 以「週」為單位顯示主場骨架時段，點格指派主／客隊、拖曳換時段；衝突格即時標紅；右下角浮動鈕可開「對戰表」查進度 |
| **賽程預覽** | 排出的成品樣式，可篩選單一球隊檢視 |
| **進度總覽** | 整體完成度、對戰組合矩陣、各隊主客場數、衝突清單、白名單外場次清單 |
| **賽程分析** | ①**公平性檢視**：各隊在各出賽日的主客場數 + 一週三戰次數；②**對戰分布**：以季中日期切上下半季，檢查各隊主場對單一對手是否群聚（3-0／0-3 標紅） |
| **主場檔期日曆** | 依球團回報的白名單，逐月列出每天有哪些隊伍可以排主場；可匯出 Excel |
| **隊伍與賽季** | 隊名、主場名稱、隊色、LOGO；賽季起訖、季中日期、出賽時段、主場輪數；清除所有客隊／清空賽程 |
| **禁排與場館** | 全聯盟禁排、單隊禁排、各隊主場可用檔期白名單（可下載 Excel 模板給球團填、再上傳解析，或直接在月曆上點選） |

## 賽制

預設 7 隊、每隊主場對每個對手 3 場，全季共 **7 × 6 × 3 = 126 場**。隊數與主場輪數都可在「隊伍與賽季」調整，總場次與各項目標會自動重算。

預設出賽時段為週三 19:00、週五 19:00、週六 14:30/17:00、週日 14:30/17:00。

## 主場可用檔期（白名單）

這是本工具的核心限制機制，行為值得先講清楚：

- 球團回報「主場**可以使用**的日期」，匯入後成為該隊的白名單。
- **一旦某隊有白名單，該隊主場就只建議排在清單內的日期**；完全沒上傳的隊伍主場不受限制。
- 若真的必須排在白名單外，**排入時會跳警示讓你確認，但不會擋你**。
- 排入後**不會更動白名單**，該場次會在排程頁（橘色左框＋「白名單外」標籤）、賽程預覽、進度總覽持續標示，方便後續跟球團確認場地。等你把該日正式補進白名單，標記自動消失。

> 沒有「協調中／確定」的檔期狀態。白名單只代表球團回報的事實，排賽動作不會竄改它。

三種輸入方式：下載 Excel 模板給球團填後上傳、在「禁排與場館」的月曆上直接點選批次加入、或手動逐筆。可重複上傳，採累加。

## 衝突檢查

工具會即時掃描下列規則，紅色為硬性衝突、黃色為提醒：

1. 🔴 **共用場館衝突** — 同週同一場館出現兩隊主場
2. 🔴 **週末主場未成對** — 週六主場沒有對應的週日同時段主場（六日成對）
3. 🔴 **客隊長途移動** — 客隊週六、週日兩天作客地點不一致
4. 🟡 **一週三戰** — 任一隊單週出賽 ≥ 3 場

> 工具只負責「標記」，不替你定義對錯；是否可接受由賽務判斷。

## 匯出

### 總賽程 Excel（頂欄「⬇ 匯出 Excel」）

產出含 **1 + 隊數** 個分頁的活頁簿：

- **`總賽程`**：全部場次總表。
- **每隊一頁**（分頁標籤上該隊主色）：三個區塊**橫向並排**，可整頁交給該球團。

  | 欄 | 內容 |
  |---|---|
  | A–G | 完整總賽程 |
  | I–O | 該隊主場賽事 |
  | Q–W | 該隊全部賽事 |

欄位為 `場次 / 週次 / 日期 / 星期 / 時間 / 主場 / 客場` 共 7 欄。全表微軟正黑體、藍底白字標題與表頭、黑色細框線、水平垂直置中，主客場欄填該隊主色。場次號為總表全域編號，各區塊沿用同一套編號以利對照。

### 主場檔期日曆 Excel（日曆分頁工具列）

逐月呈現每天可排主場的隊伍，含隊色、✓（已排定主場）、禁排日紅底、賽季外灰底。匯出內容跟隨畫面上的篩選條件，副標題會註明目前條件。

### 賽程表名

頂欄的「賽程表名」輸入框決定匯出的主標題與檔名，例如 `2026-27 TPBL 總賽程 V4`。隊伍分頁的區塊標題會自動取「總賽程」之前的文字當賽季前綴，變成 `2026-27 TPBL 戰神 主場賽事（18 場）`。

> 版本號請放在**尾端**。若寫成 `V5 2026-27 TPBL 總賽程`，前綴會變成 `V5 2026-27 TPBL`。

## 使用方式

### 線上
直接開啟 GitHub Pages 網址即可。進度會**自動存到本機瀏覽器**（localStorage），但這只綁這台電腦、這個瀏覽器——換裝置或清除瀏覽資料就會消失。

### 跨裝置 / 交接
用右上角「💾 存檔」匯出 JSON 進度檔，換裝置時用「📂 載入」讀回。**JSON 是唯一可攜、可備份的真實檔。**

### 本機執行
因為用了兩個 CDN 函式庫，**需要連網**才能使用 Excel 上傳與匯出（排程本身可離線）。要完全離線需把函式庫下載進 repo 並改為相對路徑，做法見交接文件。

### 兩種「清除」的差別

| | 清除所有客隊 | 清空所有賽程 |
|---|---|---|
| 比賽場次 | 全部保留 | 全部刪除 |
| 日期／時間／主隊／週次 | 全部保留 | 一併消失 |
| 客隊 | 改為「待訂」 | — |
| 白名單、禁排、隊伍、賽季 | 不動 | 不動 |

兩者都不可復原，動手前請先存一份 JSON。

## 技術架構

- **單檔**：`index.html`（約 3,280 行）＝ HTML 結構 + 內嵌 `<style>` + 內嵌 `<script>`，全部在瀏覽器端執行。
- **函式庫（CDN，Cloudflare）**：
  - [SheetJS](https://sheetjs.com/) `0.18.5` — 解析球團上傳的檔期 Excel、下載填寫模板
  - [ExcelJS](https://github.com/exceljs/exceljs) `4.4.0` — 匯出賽程與日曆（支援儲存格底色，SheetJS 社群版不支援）
- **資料保存**：localStorage 去抖動自動存檔 + JSON 手動存/載。
- **部署**：GitHub Pages，單檔即整站。

## 資料模型

所有狀態集中在全域 `state` 物件，存 JSON 時即整包序列化：

```
state = {
  teams:          [{ id, name, venue, color, logo }],   // venue 相同＝共用場館
  season:         { start, end, midDate },              // midDate 空＝畫面自動帶行事曆中點
  schedTitle:     '2026-27 TPBL 總賽程',                // 匯出 Excel 的表格標題與檔名
  analysisDays:   null,                                 // 公平性檢視顯示哪幾個出賽日；null＝自動
  slots:          [{ day, time }],                      // day: 0=日…6=六
  homeRounds:     3,                                    // 每隊主場對每對手的場數
  leagueBlackouts:[{ id, start, end, reason }],
  teamBlackouts:  [{ id, teamId, scope, start, end, reason }],  // scope: both|home|away
  venueAvail:     [{ teamId, date, time }],             // 白名單，time:'' ＝全天
  matches:        { 'YYYY-MM-DD|HH:MM': { home, away } },  // away 可為 'TBD'（待訂）
  meta:           { savedBy, savedAt }
}
```

舊版 JSON（`venueAvail` 帶 `status` 欄位）可直接載入，會自動遷移。
